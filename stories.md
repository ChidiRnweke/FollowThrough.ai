I move beteween projects, I need to think about how the chat bar behaves, how that "movement" feels, does it stay behind or move with you and get "confused"; Maybe the agent should know and tell you "hey we're not in a different project? Want me to clear / archive this chat and we start again?" If you say yes it does a tool call that restarts your chat (+ changes the UI) and refires the question, scoped into the new one.

Every meaningful UI action should have a semantic equivalent the agent can invoke—not by faking clicks, but through the same underlying commands the interface uses.

Then the UI becomes a shared surface between you and the agent. You can act manually, ask the agent to act, interrupt it, undo it, or continue from what it changed. That continuity is what makes the AI feel native rather than bolted on.

The ideal feeling is: anything I can do, I can ask—and I can watch it happen.
