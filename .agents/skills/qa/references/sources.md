# Source

Based on Vladimir Khorikov, _Unit Testing: Principles, Practices, and Patterns_, Manning, 2020.
The Python, TypeScript, and frontend examples are original applications of its principles.
No source PDF is needed to use this skill.

Typed handwritten substitutes rather than mocking libraries are this skill's policy;
the book permits library mocks. Keep project commands, paths, and architecture in project
instructions. Do not turn example assertion counts, suite ratios, or framework choices into rules.
