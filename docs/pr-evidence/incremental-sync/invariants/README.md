# Sync review evidence

These images compare PR #37 at `56d855c` with the invariant-driven review. They do not show the application before this PR. The scenarios use the real Svelte review and menu with representative in-memory records, without model calls or private data. Menu before images reuse the matching captures already committed with that PR.

The separate production PWA suite uses minted authentication and a disposable PostgreSQL database. All 26 scenarios passed, including offline persistence, review, cross-tab observation without focus, and startup during a stalled write. Those behavioral checks are distinct from these component captures.

Desktop is 1280 × 720; mobile is 400 × 800. The same queued project and competing project names are used before and after. The [recorded computed styles and control bounds](layout-measurements.json) verify the final detail title is 18px/600, status 14px, title/status gap 4px, header gap 12px, and frame gap 24px. Every visible action fits in the viewport.
