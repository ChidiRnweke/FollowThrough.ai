Todos track commitments: things you owe, and things you are waiting on from other people. They live on the Todos page across all projects, and under each project at `Project > Todos`. Both surfaces show the same workspace; the project one is pre-filtered.

A todo is more than a title. It carries a status, an optional priority, category, and due date, a responsibility — **Mine** or **Waiting on** someone, with their name — and, when it came out of a note, a link back to the exact sentence that created it.

## Board and list

<Screenshot id="todo-board" alt="The todo board with Backlog, Open, In progress, and Done columns" />

Board and List are two views of the same set, switched by tabs in the toolbar; the choice is part of the URL, so a link lands on the same view.

The **board** has four columns: Backlog, Open, In progress, Done. Drag a card between columns by its handle (revealed on hover), or use the card's **Move to…** menu. The checkbox completes a todo; unchecking reopens it. Each column except Done has an **Add** row at the bottom — type a title, Enter commits, Escape cancels. A card shows only what is set: project badge on the all-projects page, a due-date badge that turns red when overdue, a priority badge for medium and high, and a footer with the source note and who the todo waits on. An empty column says so in one line ("Nothing in flight.").

The **list** is a table with a column per field. Click a header to sort ascending, again for descending, a third time to return to the default order — due date first, then recently updated; todos without a value always sort last. Status, priority, category, due date, responsibility, and source are editable in place: the control appears on hover or keyboard focus and commits the moment you choose. On phones each row becomes a card with the same fields.

Filters sit above both views: a title search box, dropdowns for project and category, and **Mine** / **Waiting on** pills. The dropdowns and pills live in the URL and are shareable; the search box just narrows what is already loaded. Category options are the categories your todos actually use.

## The detail panel

Clicking a title opens the todo's details — a side panel on wide screens, a full page below that. Everything is editable in place: text fields commit on blur or Enter and restore the saved value on Escape; selections commit immediately. There is no Save button. The counterparty field appears only while responsibility is Waiting on.

Two sections matter beyond the fields. **Original context** quotes the sentence the todo was extracted from, with a link into the note at that passage. And **Find the source** asks the agent to locate the note a todo came from and explain what it says. Deleting a todo asks for confirmation and removes it from every board, list, and note that references it.

## Promises from your notes

Select text in a note and the bubble menu offers **Extract promises**. Each genuine commitment in the selection — not questions, suggestions, or floated options — becomes a suggestion card in the note's Suggestions panel, showing the action, who owns it, the due date with its original wording, and a strength badge when the promise is implied or tentative rather than explicit. **Accept** creates the todo; **Dismiss** drops the suggestion. Either way the todo keeps the quoted sentence as its original context.

In Settings you can set the Extract Promises pipeline to auto-accept, optionally only above a confidence threshold. Auto-accepted suggestions become todos immediately, announced by a toast, and stay visibly marked as auto-accepted. The toolbar's **Find todos in my notes** action hands the same job to the agent across your notes instead of one selection.

## The edges

- A todo belongs to one project for its whole life; editing cannot move it.
- Cancelled exists only in the status dropdown — it is not a board column.
- Completing stamps the completion date; reopening clears it. Switching responsibility back to Mine clears the counterparty.
- Extraction failure creates nothing — no anchor, no suggestions — and tells you to try again.
