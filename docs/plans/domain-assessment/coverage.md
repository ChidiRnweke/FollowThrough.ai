## What these numbers do not prove

Family assignment is a navigation aid, not a proof of a call edge. `source-inventory.json` includes
literal imports, exports, controller signatures and test titles so the next reader can trace both
callers and dependencies. Dynamic dispatch, runtime factories, template handlers, re-export resolution,
SQL behavior and generated SDK tools still need human reasoning. Svelte inventory parses script bodies,
not every markup event. Model exports include request types, schemas and helpers; they are not 824
distinct domain objects. The 411 item checkboxes remain open until individual review evidence is recorded.

The static inventory intentionally excludes vendor dependency code, binary assets, generated build output,
CSS, SQL and configuration JSON. SQL ownership/ordering was separately reviewed in `workspace.md`;
design tokens, deployment and build configuration need their own evidence when changed. Zero unclassified
paths is not zero unreviewed behavior. No repository-wide semantic certification is claimed.

## Corrections to the initial workflow vocabulary

- W16.20: the code named `ConversationSummary` generates a search query; it does not compact stored
  dialogue. Assess query condensation and provider replay separately. Do not implement a nonexistent
  history-compaction feature just because the initial inventory used that phrase.
- Diagram promotion is Mermaid-to-draw.io conversion, not moving a diagram into a project.
- Generated-artifact regeneration is documented to use current sources, not historical replay.
- Several lifecycle verbs share one workflow family but must retain separate concurrency/approval tests.
