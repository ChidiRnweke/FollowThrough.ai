# Controller and model audit

## Contract and scope

Models describe data: types, values and Zod schemas. Boundaries parse external data with Zod.
Services calculate and decide using typed values. Controllers coordinate services and transactions.
Pure calculations, document readers and formatting functions do not belong in models.

This audit covers current server and browser controller capabilities, their callers/dependencies,
and every model namespace. Unrelated editor, UI, PWA and infrastructure reviews remain open.
Source inspection is not runtime verification. A passing architecture suite is not semantic certification.

Historical assessment reports and generated inventories have been deleted. Their evidence remains in
[the pre-deletion snapshot](https://github.com/ChidiRnweke/FollowThrough.ai/blob/1ed8135c791115a033ad4b5ec33d6e2f95c5f17d/docs/plans/domain-assessment-plan.md) and the linked PRs.

## Current findings and delivery

The implementation below is on the audit branch. Verification results are recorded at the end.

| Finding                                 | Result                                                                                                                                                                                                                                                                               |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Model calculations, readers and runtime | Export preparation, widget formulas and cycle checks, token counting, catalog queries, model IDs, workspace identities and sync versions now have service or factory owners. XML/protocol readers live in their adapters. Models retain data, schemas and plain record constructors. |
| Boundary parsing                        | Payload, session and note consumers invoke shared Zod schemas. Payload parsing preserves own `__proto__` keys; corrupt stored documents remain visible. Virtual filesystem paths decode into typed resource identities in the input adapter.                                         |
| Root agent grep                         | `/` and `.` both search the root and return matching files.                                                                                                                                                                                                                          |
| Conversation and trust-policy reset     | PostgreSQL updates explicitly store NULL when optional overrides or the threshold are cleared.                                                                                                                                                                                       |
| Diagram creation                        | Insertion and indexing share one controller transaction; indexing failure rolls back the diagram.                                                                                                                                                                                    |
| Widget source scope                     | Creation requires an owned source note in the target project.                                                                                                                                                                                                                        |
| Attachment removal                      | Migration 0062 adds durable object-removal work. All version keys are queued with record deletion; rollback restores records and removes queued work. A scheduled worker retries storage failures after commit. Note snapshot bytes remain retained.                                 |
| Archived-project access                 | Direct diagram reads/writes/history and deliverable artifacts/templates/settings require an active owned project. Template reservation cleanup remains available.                                                                                                                    |
| Session deletion race                   | Submission and deletion lock the same conversation before deciding. PostgreSQL tests cover each operation winning the race.                                                                                                                                                          |
| Controller policy placement             | Memory visibility, suggestion grouping/order, inline eligibility, task-edit eligibility, promise responsibility selection, preference ranges and attachment processing status now belong to services. Controllers retain cross-service coordination and transactions.                |
| Enforcement                             | Zero-baseline source rules reject model procedures and mutable module declarations/classes. Fixtures allow schema construction, schema callbacks and plain record constructors.                                                                                                      |

Widget edits still validate computed JSON-patch results and component props against the catalog,
as required by ADR 0043. Their inputs are typed; formula evaluation and dependency rules live in
the service. This validation is distinct from decoding external request or storage data.
